# Расчёт МАЭД

Расчёт — оценка среднего по участку с допущением, что точки протокола можно
рассматривать как одну серию. Применимость этого допущения и состав бюджета
неопределённости не устанавливаются автоматически. Это не заявленная проверка
соответствия методике лаборатории.

По предоставленным пользователем скриншотам раздела VII МР, формулы (8)–(14):

- среднее `mean = sum(x) / n`;
- абсолютная стандартная составляющая A `a = sqrt(sum((x - mean)^2) / (n*(n-1)))`;
- относительная составляющая B `b = sqrt((theta^2 + sum(theta_i^2)) / 3)`, в процентах;
- `uc = hypot(a / mean * 100, b)`, в процентах;
- абсолютная расширенная неопределённость `U = 2 * uc * mean / 100`;
- строка δ в таблице пользователя содержит U, строка H̄ + δ — сумму без предварительного округления.

Нужно `n >= 2` и положительное среднее. Формулы для однократного измерения (7),
(13) автоматически не применяются: погрешности ΔX в файле нет, столбец ±U_i
содержит уже расширенные неопределённости. Их нельзя подставлять вместо ΔX
или θ либо повторно добавлять к бюджету без обоснования.

Источник основной погрешности «Зяблик» + БДКГ-Р20Д:
https://www.doza.ru/files/zyablik-opisanie_2021.pdf — описание типа 75812-19,
утверждено 03.08.2021 №1603, таблица 2, лист 5: ±13 %.
Там также указаны температурная погрешность ±3 % на 10 °C, энергетическая
зависимость и анизотропия. Профиль по умолчанию содержит ТОЛЬКО 13 %.
Дополнительные составляющие не определены по условиям измерений; отсутствие
их в настройках обозначается в интерфейсе как неполная оценка.
Неизвестному прибору профиль 13 % не назначается.

Пользователь может задать основной и дополнительные пределы погрешностей
(в процентах, не готовые стандартные неопределённости), либо ввести готовую
абсолютную расширенную δ вручную. Параметры и ручное значение сохраняются;
сохранение параметров автоматического расчёта отменяет ручную δ.
При ручном значении интерфейс явно указывает его происхождение.

Для 0.15, 0.13, 0.12, 0.12, 0.14 и theta=13 %, без дополнительных составляющих:
mean=0.132, a≈0.00583095, U≈0.02299176, mean+U≈0.15499176.
Отображение: 0.13; 0.02; 0.15; 0.15; 0.12 мкЗв/ч.
